# Folien zur Vorlesung

Dieses Verzeichnis enthält die Folien, die in der Vorlesung verwendet werden.

Für jeden Foliensatz gibt es zwei Versionen: Eine "normale" Version, die für die Vorlesung gedacht ist, und eine "Handout"-Version.
Die beiden Versionen sind inhaltlich identisch, unterscheiden sich aber in der Darstellung:

- Die "normale" Version ist für die Vorlesung gedacht und enthält ggf.
  Animationen bzw. schrittweise Einblendungen von Folieninhalten.
- Die "Handout"-Version ist für die Nachbereitung bzw. für das Einfügen
  eigener Notizen gedacht. Alle Folieninhalte sind auf einmal sichtbar.
